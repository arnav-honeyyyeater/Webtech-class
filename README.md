# Cute wali website (Pani Puri)

A responsive single-page multimedia web application featuring sidebars, video showcases, and a feedback section.

## Live Demo
This branch (`Panipuri-desgin`) is configured for GitHub Pages:
- Live URL: `https://arnav-honeyyyeater.github.io/Webtech-class/`

## Assets & Structure
- `index.html` - Primary entry point for GitHub Pages
- `desgin.html` - Website design file
- `kuro logo.jpg` - Site logo and favicon
- `chikyu-daibakuhatsu.mp4` - Video showcase 1
- `deadline-disco.mp4` - Video showcase 2 (MP4)
- `disco.webm` - Video showcase 2 (WebM fallback)
- `deadline-poster.jpg` - Video 2 poster image
- `.nojekyll` - Ensures GitHub Pages serves static media without Jekyll processing
